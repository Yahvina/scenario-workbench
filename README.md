# 情景研判平台 · Scenario Workbench

用交叉影响平衡（CIB）方法组织政策情景，查看因素之间的影响，并检验情景是否自洽。

## 在线打开工作台

**[点击直接打开情景工作台](https://yahvina.github.io/scenario-workbench/)**

## 离线使用

**[下载离线工作台](https://github.com/Yahvina/scenario-workbench/raw/refs/heads/main/docs/index.html)**

下载后双击 `index.html`，用浏览器打开即可。若链接显示文本，可到 [工作台文件页](docs/index.html) 点击右上角的 **Download raw file**，然后打开下载的文件。离线使用无需安装 Node.js。

使用 Node.js 22 或以上。


打开 [本地开发入口](http://127.0.0.1:4173)。单文件构建位于 `dist/scenario-workbench.html`。

## 当前版本能力

- **因素与年度方案**：默认载入《京津冀政策描述符体系》（10 个领域、34 个细分领域、46 项具体描述符，另有 2 项结果指标单列）。分类已确认；三档状态为平台参考设定，阈值与依据未核定。
- **关系判断**：有向状态对评分 −3…+3，0 表示没关系、空白表示未判断。适用地区与年份默认取当前研究范围，可修改。
- **参考评分**：按因素身份匹配可核对的参考规则，只填空白格，来源与填入范围在采用前先行展示。
- **CIB 检验**：精确枚举离散状态组合，给出自洽组合数与逐因素支撑分；精确枚举上限为 100000 个组合。
- **白箱链**：计划检验记录、公式代入与结果可反查。
- **保存与导出**：命名方案、检验归档、整库导出与恢复，以及中文报告与模型输入样例。

## 方法与边界

- CIB 检验离散状态组合的自洽性，不预测现实，也不做效益最优化。自洽不等于必然发生。
- `0` 表示没关系，空白表示未判断，两者不能互相替代。
- A→B 与 B→A 相互独立。
- 分类粗选不等于存在合法聚合模型；按年选择不等于跨期动力学。
- 平台只会填入经核对的参考规则，不虚构证据；缺依据时如实保留缺口。

仓库为清理后的源码发布镜像，许可证待选。

联合改分方案支持命名保存到当前浏览器、同冻结基线载入重算、两方案并排比较和完整JSON导出。跨年份、地区、评分或条件的基线拒绝直接套用；最多12份/2MB，存储失败不覆盖。当前325项单测中324通过、1项真实服务调用跳过，保存/刷新/实际JSON下载重算与原流程均经浏览器核验。
