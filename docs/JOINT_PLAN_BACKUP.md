# 联合方案备份与恢复

项目备份和联合方案备份是两个文件。迁移时请同时保留；“导出两方案比较”保存的是比较结果，不能替代方案备份。

1. 在原设备导出项目备份。在“稳健性检验 → 保存与比较联合方案”点击“导出联合方案备份”，下载本机全部联合方案。
2. 在新设备恢复项目，按原年份、评分选用和给定条件重新检验，进入稳健性检验。
3. 在“导入联合方案备份”选择备份文件。导入合并本机记录，不删除已有方案。
4. 选择方案，点击“载入联合方案”，再点“联合重算并比较”。也可选择两份方案并排比较。

重复导入完全相同的记录会跳过。同一标识内容不同、同一冻结基线同名、格式无效或合并后超过12份会整批拒绝；已有记录保留。备份上限2MB。

其他基线的方案可以保存，但不能直接应用于当前基线。年份、矩阵或条件变化后，请恢复原设置重新检验；不要通过修改备份标识绕过检查。导入不会更改当前项目的评分。

技术格式：`format=scenario-workbench.joint-plans`、`version=1`，每条记录保存名称、标识、日期、冻结输入和改分列表。文件含研究输入，请按项目资料要求保存。
