# Scenario Workbench / 情景研判平台

模块化、离线优先的 CIB（Cross-Impact Balance）情景工作台。

当前代码对应已集成本地基线 `85ef6d9`。已实现：多级描述符选择、政策实施路径、有向状态对评分、有限二档模板编码、精确CIB枚举、逐项贡献与冲突解释，以及冻结输入JSON归档。双视角共用数据和算法。

需要 Node.js 22 或以上，无第三方运行时依赖。

```sh
npm test
npm run build
npm start
```

默认访问 http://127.0.0.1:4173；离线产物为 dist/scenario-workbench.html。可用 `node scripts/serve.mjs 4188` 换端口。浏览器回归另需自行配置 Playwright、Chrome 和 APP_URL，见相应测试脚本。

CIB支持精确枚举，最大100000组合；锁定仍与全部候选状态比较，并列最大允许成立。0表示没关系，null表示未判断，缺分不补0。完成零解、阻断和取消区分；输入变化使旧结果过期。结果只在会话中保留，刷新后不恢复，长期保存请下载。

一致性不等于现实发生概率、减排绩效或动态预测；测试与草案不是已核验的政策结论。23个有限二档模板可用，L13停用、A2保留冲突警告，不自动外推三档。尚无AI服务、抽样、优化、完整报告或模型参数出口。

此仓库为清理后的代码发布镜像，不含录音、论文全文、内部任务/交接/审查与本地开发历史。测试81项通过，浏览器覆盖范围以实际测试脚本为准。开源许可证尚待选择，当前未附许可证。

P1：加入框架保留项目范围及非冲突数据；粗选可定位下级变量；矩阵候选须重验并明确采用，假设单独确认。公共保存页提供项目备份及当前查看的真实检算JSON归档。完整报告、长期运行恢复仍待后续实现。

P2：普通五项任务导航与可选时间分支、专家规划工具折叠、中文结果/冲突和可展开技术详情、紧凑项目信息。主摘要前置，设置展开状态保留；原科学校验及下载不变。81项产品测试、相关源码/离线主线与长名称诊断检查通过，极长名称展开仍会拉长页面。

P3首包：界面创建/编辑因素与状态，含角色、定性/数值区间、单位、年份地区和已有依据。定义变化前预览确认，原判断/路径完整保存于修改历史；当前评分清为未判、路径状态待核，旧候选和结果失效，历史运行归档保持。75项测试及源码/离线空项目→八格→两解→改定义→旧评分拒绝、并发和失败保护通过。尚无删除、全树管理、分数迁移或自动时间状态映射。

P4首包：显式保存命名方案及真实检算归档，关注与锁定分离；刷新后历史查看下载、整库确认导入、冲突/损坏/配额失败保留原数据。独立格式见docs/SAVED_WORK_V1.md；历史始终标本会话未复算，不自动成为当前计算。20条方案+20条归档及5MiB限制，81项产品测试。完整复算、库管理、比较、同步仍待续包。
