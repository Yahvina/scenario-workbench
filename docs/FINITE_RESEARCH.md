# 有限范围研究与案例交接

专家界面 → 稳健性检验 → “研究工具：有限范围内的最小联合改分”。普通用户主线保持原有入口。

载入合成示例、导入研究JSON，或使用当前已完成检验的冻结矩阵。可以将评分格加入原分±1范围，选择独立、同幅或改变量和为0；导入文件也支持多个重叠联动约束。研究输入不写回活动项目。更换输入或约束即作废旧结果。

研究JSON沿用本项目研究原型字段：`sizes`、`cells`（来源因素、来源状态、目标因素、目标状态、评分）、`uncertain`（cell和values）、`equal_delta_groups`、`sum_preserving_groups`、`fixed`、`mode`。坐标从0起。完整有向整数矩阵，−3至+3；每个范围含原值。未知字段、缺分、重复格、越界、非法约束均拒绝。`ordinary`不含固定状态；`locked`仍检查固定因素自身，`conditioned`免检给定因素自身，保留对外影响。当前不从平台导出同次混合两类固定条件的矩阵。

交互预算：每张矩阵最多10000种配置，默认10000个取值组合、200000次配置检验。完整有限枚举或达到[1,1]整数通用下界时才报告最小性；无变化且完整枚举后仅报告“在声明范围内不变”。取消、超限可下载已知记录，不得解释为最小性成立。预算是组合工作量，不保证硬件运行时间。正式独立包0.1.1未增加此研究接口或取消能力。

同一导入入口接受`cib-case-handoff` v1案例交接文件。字段、引用及模型确认未齐时，仅显示和导出缺项，禁止复算。齐备时分别给定三种支持状态，只检验能耗状态，不补反向评分。结构齐备不代表科学依据已经独立核验，也不代表已完成河北实证。

验证：与既有84个精确真值及36个保持和/混合约束输入核对，120个复用输入的状态和代价一致。新增浏览器回归覆盖实际下载、停止、坏文件、缺项案例及项目不变；合成测试不是河北真实数据。软件接口集成不改变2026-11-19选题去留审查的创新判断。
