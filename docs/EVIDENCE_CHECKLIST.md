# 评分依据核验清单

检验页从最近一次冻结RunInput与projectInputSnapshot提取实际使用的判断，按方向整理引用、具体定位、记录审核状态与待核对任务。给定条件下只列实际进入本次矩阵的方向和评分行，不能将未使用的反向判断混入统计。

`evidenceChecklist(archive)` 是只读整理函数，输出包含冻结输入，`evidenceAdequacy` 固定为 `not-established`。它不会读取论文正文、确认历史数据真实性、自动判断引用是否支持某个分数，也不改变原有计算闸门。

论文和历史数据类型的引用只计为规律类候选。已作为曲线编码来源的引用、以及与现有评分方法论文DOI匹配的引用单列为评分方法引用，不计作关系规律引用；不能理解为程序已识别所有方法论文。其它候选仍需人工检查内容。

记录的 `reviewStatus=reviewed` 不代表方向、强度、状态划分、地区和年份已分别得到独立核验。0分是明确判断没关系，与没有引用或低置信分开。取消或未完成的检验保留其计算状态，不因清单存在而成为完整结论。

引用内容由数据同学采集核验；模型负责人审定条件、模型口径和结果解释。导出清单用于核验与交接，不是科学有效性认证。

单测覆盖0值语义、已审核元数据的边界、评分方法来源排除、缺失引用、冻结输入隔离和条件矩阵范围。浏览器验收检查实际下载内容与原项目不被改写。
