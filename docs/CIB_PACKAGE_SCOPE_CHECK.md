# 独立算法包范围验证

`node scripts/check-cib-package-scope.mjs <cib-core目录> <报告目录>` 使用独立包的 index.mjs、pruned.mjs 和 tests/reference.mjs，生成定种子输入及完整结果核对记录。需要 Node 22+；路径含空格时加引号。该工具不会把项目JSON自动转换为独立包请求，也不改变生产求解器。

2026-11-16在固定0.1.0交付包执行：72张合成矩阵，六种状态结构（2×2×2、2×3×4、3×3×3×3、2×3×2×4×2、六个二状态、六个三状态），每张普通求解及单/双因素给定、锁定共五次，合计360组。生产独立枚举、直接枚举参考和研究剪枝入口完整集合全部一致。参考实现随该包的测试文件提供，因此这是实现对照，不是独立机构认证。

相同360组输入另经固定PyCIB提交 b3c3eece6d747819afb8041c3fd5df1ba861e2f0 的安全上界与无剪枝配置各执行一次，共720次，完整集合匹配。外部运行适配器及明细保留在本地研究材料，不属于本脚本；给定免检依然使用显式中和输入影响的适配，非外部原生同名接口。全部新增输入未逐一通过平台界面运行。

七项边界核对覆盖相关缺分阻断、给定目标免检、未选择来源行、全部给定拒绝、并列最高、恰好100000候选允许，以及固定状态后候选数下降。二状态8/12/16因素分别完整检验256/4096/65536候选；17因素131072候选返回space-limit，不能解释为零解。

脚本记录单次耗时与前后进程内存。没有预热控制、重复性能试验或峰值采样，不能据此推断硬件最低要求、并列大量解的输出成本或求解器性能领先。矩阵为固定种子样本，三因素以上未穷举；研究剪枝仍未替换平台生产枚举。算法正确性验证不替代评分证据、研究创新或真实使用评价。
