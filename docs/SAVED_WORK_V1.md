# 本地方案与检算历史格式 V1

P4首包。实现位于 `src/modules/workspace/saved-work.mjs`，不改变 Project、RunInput、RunResult 或原检算封套契约。

```json
{
  "format": "scenario-workbench.saved-work",
  "archiveVersion": 1,
  "plans": [
    {"id": "plan-id", "name": "方案名称", "createdAt": "2026-11-03T00:00:00.000Z", "project": "此处为完整Project对象"}
  ],
  "runs": [
    {"id": "run-id", "name": "归档名称", "createdAt": "2026-11-03T00:00:00.000Z", "archive": "此处为原JSON检算封套对象"}
  ]
}
```

上例的 project/archive 字符串仅作结构占位，真实文件必须为完整对象。顶层只支持这四个字段；未知格式、版本和顶层扩展字段拒绝。记录名称和ID非空，ID在两种记录间全局唯一。日期为合法ISO日历时间，带Z或明确时区偏移，不归一化原日期。JSON数值必须有限，不接受非JSON值、循环或稀疏数组。

## 保存与恢复

- 独立 localStorage 键 `scenario-workbench.saved-work.v1`；不覆盖现有项目键。公开常量 `MAX_ITEMS=20`（每种记录）、`MAX_BYTES=5242880`（5MiB）。导入原文件字节和紧凑序列化后的整库均受上限约束，导出使用紧凑JSON。浏览器实际配额也可能更小。
- 保存是显式操作，不自动复制运行。记录及读写返回值均深拷贝；方案包含完整项目数据，不引用当前项目。关注状态只写保存副本的 `selection.stateIds`，每活动因素最多一个，未选允许；`lockedStateIds` 原样保留。当前项目及修订不变，不从 inspection 推导关注，不把关注当锁定。
- 方案恢复先展示目标范围、关注和锁定，提示备份，再确认、校验、单次 `actions.replaceProject`。取消、拒绝及提交失败不改当前项目。恢复不会自动采用矩阵、计算或恢复求解会话。
- 整库/旧单归档导入先预览，再明确确认合并。同ID相同内容幂等（对象键顺序不影响相等）；同ID不同内容或跨类型ID冲突整批拒绝，不覆盖或改ID。合并保留旧记录顺序，新记录追加。
- 写入前完成整库校验、序列化、容量检查，并检查旧原始值未变化，只调用一次 `setItem`；成功返回后才更新界面和成功提示。解析、校验、容量、存储访问或配额失败保留原数据。该检查不是跨标签事务锁，不承诺多窗口同时写入的一致性；本包按顺序Local使用。
- 原库损坏时不清空、不覆盖、不允许普通保存/导入；可下载原始字节字符串，重建空库须明确确认。重建不改当前项目。库满时拒绝新增，不自动删除旧历史。

## 原检算封套兼容与科学边界

旧Project备份继续从原项目恢复入口处理，历史库入口拒绝。旧单条检算封套可导入：不修改内部归档，只加外部记录。存在结果ID时使用 `legacy-<结果ID>`；前置阻断使用规范化内容的32位摘要生成 `legacy-preflight-…`。重复导入复用既有外部名称和日期，保证幂等；摘要不是签名，碰撞产生不同内容时仍整批拒绝。

归档验证复用既有 `validateProject`、`inspectInput`、`prepareRun` 和 `explain`，不放宽S1/J1原闸门：

1. 校验完整科学快照、原确认、诊断、选用判断ID/版本/依据引用、年份/地区、定义、选择、矩阵及输入快照。对有效输入，使用冻结项目及原确认重建并比较输入与诊断；当前V1要求诊断内容相等，不猜测迁移不同版本的诊断。
2. 核对受约束/未约束空间、limit及coverage。完成状态要求 checked 等于受约束空间，count 为0…checked整数，场景、解释、截断语义一致。未完成状态 count 必须为null。取消保留原 failed、局部发现数及原因，不冒充零解。
3. 原始分值和封套不修改；展示配置逐个调用 explain，与原 balanceTrace 比较，要求自洽且不违反锁定。inspection 如存在，仅检查可解释性，不把人工查看配置当自洽结果或方案选择。
4. 前置阻断允许 RunInput/RunResult 同为null，必须保留阻断诊断和科学快照；不要求不存在的完整矩阵。内核拒绝的 blocked 可含无效输入，以“拒绝记录”保留，要求零检查、空结果、null计数以及与可检查性一致的空间/coverage；不作为有效输入复算。

所有持久历史，包括本浏览器保存的真实运行，均在折叠详情外标明 **“历史归档，未在本次会话复算”**。展示的是归档声称的状态和数量。结构、来源链和逐项解释一致，只证明所展示配置的解释一致；没有重新枚举全空间，无法认证完整计数。测试特意保留“真实两解却自洽声称一解”的档案，说明这一边界。文件也不提供来源真实性签名。

历史读取不写solver会话Map，不改变当前顶栏检算状态；尚未显式保存的会话仍会随刷新丢失。完整复算恢复、当前求解输入采用、跨浏览器同步、方案比较、删除/重命名管理均未在首包提供。存储来源隔离由浏览器决定，HTTP与file页面不能假设共用库，应通过导出/导入迁移。
