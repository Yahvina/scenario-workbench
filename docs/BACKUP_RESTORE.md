# 完整备份与换设备恢复

平台有三个独立保存位置。换设备或清理浏览器前，请按需要分别下载；单个项目备份不会包含另外两份库。

|内容|下载入口|文件用途|
|---|---|---|
|当前项目的定义、评分、年度设定|保存与导出 → 导出、备份与恢复 → 下载项目备份|恢复当前活动项目|
|命名方案与历史检验记录|保存与导出 → 我的方案与历史 → 导入、导出与存储说明 → 导出完整历史库|保留多个方案及冻结检验记录|
|联合改分方案|稳健性检验 → 保存与比较联合方案 → 导出联合方案备份|恢复各方案的基线与改分列表|

建议把三类文件放进同一个带日期的文件夹。导出比较结果、报告和模型输入样例不能替代这些备份。

## 恢复顺序

1. 在新浏览器打开离线平台。进入“保存与导出 → 导出、备份与恢复”，选择“从 JSON 备份恢复”，恢复项目；恢复会替换活动项目，先保留新设备已有项目的备份。
2. 进入“我的方案与历史”，展开“导入、导出与存储说明”，选择“导入历史库或单条检验记录”。检查预览，点击“确认合并历史库”并确认。导入历史库本身不替换活动项目。
3. 如需改用其中一个命名方案，展开该方案，点击“预览恢复方案”，核对后确认替换。取消确认时项目不变。
4. 按原年份、判断选用和给定条件重新检验。历史记录显示的是当时冻结结果，不自动成为本次结果。
5. 进入稳健性检验，导入联合方案备份，再选择方案载入并重新计算。联合方案只能应用于完全相同的冻结基线，不能直接套用到另一年份或不同评分。

## 保护规则与限制

历史库最多20条命名方案和20条检验记录，导入上限5MiB；联合方案最多12份、备份上限2MB。完全相同的记录重复导入不增加副本；标识冲突或格式无效时拒绝合并。不要通过手改标识或评分绕过核验。

历史库损坏时，先下载原始数据再决定是否重建空库。存储空间不足或写入失败时，保存状态会说明失败；不要仅凭表单已填写判断保存成功。

自动化浏览器验收覆盖手算测试项目的保存、导出、独立环境恢复、零解/缺分/取消、损坏输入、确认取消、存储异常、历史冻结及窄屏。非开发者试用、用户全部实际项目和任意浏览器环境仍需各自验证。
